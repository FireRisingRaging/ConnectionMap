Connection Map

Controls
  • Left Mouse Button hold and drag a node to draw a connection arrow. A node can have any number of outgoing and incoming arrows.
  • With Segmented Nodes on, the arrow attaches to whichever part you started on and whichever part you released on (entrance, name, or exit). Only the segment under the cursor lights up as you drag. Group headers are never split, so arrows meet them anywhere along their border. Two nodes can hold several arrows as long as each uses a different pair of parts.
  • Single-click a node to highlight every chain going in and out of it, each chain in its own color. Click it again (or empty canvas) to clear.
  • Double Left Mouse Button on a node to remove ALL of its outgoing arrows at once.
  • Double-click an arrow to remove just that connection and split its chain (the part after the break becomes a new chain).
  • Click an arrow on the map (or a path in the Display panel) to highlight that path on both; click again to unhighlight.
  • Middle Mouse Button to mark/unmark a node green. Right Mouse Button to mark/unmark a node red.
  • Drag the panel background to move a group panel.
  • Triangle handle (bottom-right of each panel) to resize it. Nodes reflow automatically in that space.
  • Node triangle (bottom-right of each node, Decouple only): drag it to move that node on its own. It moves and it never resizes. Dragging anywhere else on the node still draws an arrow.
  • Hover over an arrow to see what letter chain it is part of.
  • Single-click an arrow to view its chain and what chain it can be linked to or add it to a new chain.
  • Scroll to zoom, drag empty space to pan.
Controls
  • Hold and drag any node to draw a connection arrow. A node can have any number of outgoing and incoming arrows.
  • With Segmented Nodes on, the arrow attaches to the part you started on and the part you lifted off on (entrance, name, or exit). Group headers stay whole.
  • Double-tap a node to remove ALL of its outgoing arrows at once.
  • Tap a path in the Display panel to highlight it on the map; tap again to unhighlight.
  • Single tap a node to cycle its color: green → red → none.
  • Tap once a panel's empty background to select it (border lights up), then drag from that background to move it. Deactivates automatically when you lift your finger.
  • Triangle handle (bottom-right of each panel): drag to resize it. Nodes reflow automatically.
  • Node triangle (bottom-right of each node, Decouple only): drag it to move that node on its own. Dragging anywhere else still draws an arrow.
  • Pinch to zoom, drag empty canvas to pan.
Info
  • The striped nodes are dead ends: they only accept one incoming arrow. Toggle any node's dead-end flag in the Template Editor.
  • Build your own map for any game in Edit Template: add groups and nodes, set colors, choose which headers can connect, then Apply. You can also download the template as JSON, edit it, and upload it back.
